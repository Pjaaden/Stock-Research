# 季度财报 CSV 存档工作流（可执行）

> 目标：把每一家公司的季度财报（季报/半年报/年报）用 CSV 长期归档，形成可累积、可跨期对比的财务时间序列。
> 试点：凌霄泵业（002884）——首个建档标的（2026-08-27，基于 2026 年半年度报告）。
> 定位：本文件属于"结构化数据层"的采集规范，与研究 HTML（研究报告层）、data/*.json（工作台字段）并列，互不替代。

## 一、目录与文件约定

每个标的在其 `research_folder` 下建立：

```
<research_folder>/
└── data/
    └── quarterly/
        ├── README.md                      # 数据字典 + 该标的建档信息
        ├── <code>_income_statement.csv    # 合并利润表（经营收益表）
        ├── <code>_balance_sheet.csv       # 合并资产负债表
        ├── <code>_cashflow_statement.csv  # 合并现金流量表
        └── <code>_segment_revenue.csv     # 分产品/分地区收入与毛利率（可选）
```

- 文件名为标的代码小写 + 表名，如 `lingxiao_income_statement.csv`。
- 全部 CSV：UTF-8 **带 BOM**（Excel 直接打开中文不乱码）。
- 统一 long-format（一行为一个 period × 一个科目），便于追加与程序化读取。

## 二、字段规范

| 列 | 说明 |
|---|---|
| `period` | 报告期标签：`YYYYQ1`~`YYYYQ4`、`YYYYH1`、`YYYYH2`、`YYYY`（年报）。同一份报告内的"上年同期"用上年同期标签单独成行 |
| `item` | 报表科目名（与披露口径一致，保留"其中:"前缀） |
| `value` | 数值；亏损/流出为负 |
| `unit` | `CNY`（元） / `CNY_per_share`（元/股） / `pct`（百分比） |
| `point_in_time` | 仅资产负债表：`期末` / `期初`（期初=期初资产负债表日） |
| `note` | 口径/重分类/来源说明；派生指标标注"派生计算" |

## 三、每期更新步骤（财报发布后）

1. **读旧资料**：读 `<research_folder>/data/quarterly/README.md` 与既有 CSV，确认已有 period 与口径。
2. **提取**：从当期报告（统一用**合并口径**）提取三张表 + 分部收入；保留报告内"上年同期"列作为独立 period 行。
3. **追加不覆盖**：新增 period 的行直接追加；若有会计政策变更/追溯调整，另加行并在 `note` 注明"追溯调整"，不改旧值。
4. **派生指标**：毛利率、资产负债率、OCF/净利、EPS 等派生项按需一并写入（`unit=pct`，`note` 注明公式）。
5. **更新 README**：刷新"最近更新"日期与数据源；新开标的时补齐数据字典。
6. **登记**：在 `TRAE/reports/`（或当期研究 HTML）登记本次 CSV 更新；若该标的出了研究报告，在报告中引用 CSV 作为数据底稿。
7. **同步仓库**：按 `TRAE/WORKFLOW.md` 的推送流程（SSH 或 PAT）提交。

## 四、实时行情（估值用，二级市场）

- 例行校验公开行情接口可访问性：腾讯 `https://qt.gtimg.cn/q=sz<code>`、东财 `https://push2.eastmoney.com/api/qt/stock/get?secid=<mkt>.<code>`（A股 mkt=0/1 深/沪）。
- 快照要素：现价、总市值、PE(TTM/动)、PB、股息率、52周区间、行情日期。
- 行情仅写入研究报告层与 `data/companies.json`（`price` 等字段），不写入季度 CSV（避免把瞬时价格混入会计时间序列）。

## 六、扩展指引（新标的）

- 新标的建档 = 复制本工作流 + 按该标的报表结构调整科目清单。
- 科目清单以该标的年报"财务报表格式"为准；不同行业科目不同，不强行统一科目全集。
- 年报归档时建议把"上年同期"一并保留（年报对比口径），并在 README 记录披露日期。
