# 百胜中国（YUMC / 9987.HK）季度财报 CSV 存档 · 数据字典

> 用途：按季度/半年度持续追加公司财报关键数据，积累长周期财务记录（利润表 / 资产负债表 / 现金流量表 / 分部）。
> 首次建档：2026-10-07（基于 2026 年第二季度 Form 10-Q，报告期截至 2026-06-30，2026 年 8 月提交 SEC，**未经审计**）。
> 维护规范：见 `TRAE/QUARTERLY_CSV_WORKFLOW.md`（项目标准，全标的适用）。
> **口径说明（美股标的适配）**：本标的以美元（USD）报表，故 `unit` 使用 `USD` / `USD_per_share` / `pct` / `million`（股数）；财年为自然年，与规范中的 `CNY` 体系同构，仅币种不同。

## 字段规范

- `period`：`YYYYQn`（季度）/ `YYYYHn`（半年度）/ `YYYY`（年报）。**注意美股 10-Q 同时披露"季度"与"年初至今(H1)"两套口径**，本档案两者均保留（如 `2026Q2` 与 `2026H1` 并存），报告内"上年同期"另立行（`2025Q2` / `2025H1`）。
- `point_in_time`（资产负债表）：`期末`（2026-06-30，未经审计）/ `期初`（2025-12-31，经审计）。
- `unit`：`USD`（百万美元）/ `USD_per_share`（美元/股）/ `pct`（百分比）/ `million`（百万股）。
- `note`：口径与来源说明；派生指标一律标注"派生计算"并给出公式。
- 全部 CSV 为 UTF-8（带 BOM），可用 Excel / Numbers / pandas 直接读取。

## 列结构差异（须登记，参照规范 §6.2）

**分部表 `yumc_segment_revenue.csv`**：YUMC **不按"分产品/分地区"披露**，而按**品牌/板块**披露 → `dimension` 取 `分品牌`；
- 基准列 `gross_margin_pct` **不适用**（公司不披露毛利），留空；新增列 `restaurant_margin_pct`（餐厅利润率）、`operating_profit`、`op_margin_pct`、`stores`（门店数）、`sssg_pct`（同店销售）、`system_sales_yoy_pct`（系统销售额同比）。
- `其他板块及未分摊` = 集团合计 − 肯德基 − 必胜客，**含未分摊总部费用**，故经营利润不可简单加总勾稽（收入可加总勾稽，已通过校验）。
- 门店数：集团 19,297 = 肯德基 13,789 + 必胜客 4,549 + 其他 959（派生勾稽，已通过）。
