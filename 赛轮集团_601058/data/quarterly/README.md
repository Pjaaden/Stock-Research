## 字段规范

- `period`：报告期标签，格式 `YYYYQn`（季度）/ `YYYYH1` / `YYYYH2` / `YYYY`（年报）。同一报告内的"上年同期"用上年同期标签单独成行——本目录现有 `2026H1` 与 `2025H1`。
- `item`：报表科目名（与报告披露口径一致，保留"其中:"前缀科目）。
- `value`：数值（元），亏损/流出为负；`unit` 取值 `CNY`（元）/ `CNY_per_share`（元/股）/ `pct`（百分比；比率类科目的 value 为百分数本身，如 `26.99` 代表 26.99%）。
- `point_in_time`（资产负债表）：`期末` / `期初`。本目录 2026H1 的期末 = 2026-06-30，期初 = 2025-12-31（即 2025 年末数，来自半年报"期初"列）。
- `note`：口径说明、重分类说明、来源列；**派生指标一律在 note 中标注"派生计算"**。
- 全部 CSV 为 UTF-8（**带 BOM**），可用 Excel / Numbers / Python pandas 直接读取。

## 与凌霄泵业的格式差异（重要）

赛轮中报**未披露"分产品/分地区收入与毛利率"**，披露的是**"主要子公司"经营情况**与**境外资产**。因此 `sailun_segment_revenue.csv`：

- `dimension` 取值为 `分主体` / `分地区` / `分资产`（而非凌霄的 `分产品` / `分地区`）；
- 在凌霄列结构基础上，**追加 `net_profit`（归母净利）与 `net_margin_pct`（净利率）两列**（赛轮披露的是净利率而非毛利率，`gross_margin_pct` 因此留空）；
- 子公司口径含集团内部交易，**各子公司/分地区收入之和（≈205.8 亿）大于合并营收（200.27 亿）**，`note` 已注明，不可直接加总当作合并数。

## 追加规则（每期财报）

1. 从当季报告（合并口径）提取三张表 + 子公司/分地区；保留报告内"上年同期"列作为独立 `period` 行。
2. **追加不覆盖**：新增 period 的行直接追加；若有会计政策变更/追溯调整，另加行并在 `note` 注明"追溯调整"，不改旧值。
3. 派生指标（毛利率、净利率、有效税率、资产负债率、有息负债、FCF、OCF/净利等）按需一并写入，`note` 注明公式。
4. 更新本 README 的"首次建档/最近更新"日期，并在研究报告或 `TRAE/reports/` 中登记。
5. 同步在当期研究报告（如 `赛轮2026H1中报深度解析_v21_20260910.html`）中引用本目录作为数据底稿。

## 待注意的口径点

- `有息负债` = 短期借款 + 一年内到期的非流动负债 + 长期借款 + 租赁负债（2026H1 = 146.73 亿；2025 末 = 120.54 亿）。
- `净负债` = 有息负债 − 货币资金（2026H1 = 94.66 亿；2025 末 = 74.75 亿）。
- `自由现金流` = 经营活动现金流净额 − 资本开支（资本开支取"购建固定资产、无形资产和其他长期资产支付的现金"）。
- 汇率/税率为**非线性变量**：2026H1 财务费用同比 +429.74%（汇兑净损失约 2.56 亿）、有效税率 14.65%（含 GIoBE 支柱二补足税），后续季度推演应将二者作为独立变量。
